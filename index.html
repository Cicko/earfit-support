Practice reminder troubleshooting

  1. In EarFit, open Profile and confirm Daily Reminder is turned on and set to the time you want.
  2. In iPhone Settings → Notifications → EarFit, allow notifications and sounds.
  3. Check whether Focus or Scheduled Summary delayed the alert.
  4. For a quick test, set a time a few minutes ahead, leave EarFit, and lock your iPhone.

EarFit uses local notifications, so an internet connection is not required. It deliberately skips the reminder after you complete the day’s workout.
